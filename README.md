# Vintage Firma (0.1.0)

Аддон к TerraFirmaCraft, переносящий воксельную ковку из Vintage Story. Пока реализована
базовая механика: работа с заготовкой на наковальне из кованого железа.

## Сборка

```
build.cmd build      # jar в build/libs/vintage_firma-0.1.0.jar
build.cmd test       # юнит-тесты воксельной логики
```
## Установка в инстанс

В `mods` должны лежать:

- `vintage_firma-0.1.0.jar` (этот мод)
- `tfc-1.20.1-3.2.30.jar` (TerraFirmaCraft)
- `Patchouli-1.20.1-85-FORGE.jar` (зависимость TFC)

## Механика
- Shift + ПКМ горячим слитком по наковальне — выбрать рецепт (экран выбора), слиток расходуется,
  из него создаётся заготовка
- Shift + ПКМ горячим слитком по заготовке — доложить металл
- Shift + ПКМ пустой рукой — забрать заготовку (для перегрева в горне).
- Shift + ПКМ с заготовкой в руке — положить её обратно на наковальню.
- ЛКМ молотом (тег `tfc:tools/hammers`) по вокселю — удар. Режим меняется клавишей `V`
  (тяжёлый удар / выдавить вперёд-вправо-назад-влёво / разрезать).
- Удерживание ЛКМ продолжает бить.
- При точном совпадении формы изделие выдаётся игроку; температура заготовки переносится на
  результат.

## Команды

- `/vintagefirma ingot` — горячий слиток кованого железа (1000 °C).
- `/vintagefirma heat` — нагреть предмет в главной руке до 1000 °C.
- `/vintagefirma heat <температура>` — то же, с указанием температуры.
- `/vintagefirma heat <температура> hand|offhand|anvil` — нагреть предмет в руке или заготовку на
  наковальне, на которую смотрит игрок.
- `/vintagefirma heat <температура> slot <0-35>` — нагреть предмет в конкретном слоте инвентаря.

## Замечания по балансу

- Заготовку можно перегревать в горне: забрать → положить в горн → положить обратно на наковальню.
- Заготовка не может быть сломана вместе с наковальней: блок защищён, пока в нём есть работа.
